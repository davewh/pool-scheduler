My Account

Manage your profile and account settings.

What you can do:

  • Update Display Name: Change your public name that appears in tournaments
  • Change Password: Update your password for account security
  • View Email: See your registered email address (read-only)

How to use it:

  1. Click the "My Account" button from the home page
  2. Update your display name if desired
  3. To change your password, enter your current password and your new password
  4. Click "Save account" to apply changes
💡 Tip: Your display name is shown to other players in your tournaments. Choose something recognizable!

My Tournaments

View and manage all tournaments you own or participate in.

Tournament List Layout:

The tournament list displays all your tournaments with a status indicator showing how you're involved:

  • Created by you: Tournaments you own and manage
    • Full control over settings and management
    • Can invite teams and manage results
    • Can delete or hide from public
    • Access to all tournament functions
  • Invited: Tournaments others have invited you to
    • You're a participant or team member
    • View tournament details and schedule
    • Cannot modify tournament settings
    • Can view results and standings
  • Joined: Public tournaments you've joined
    • You've added yourself as a participant
    • View tournament details and standings
    • Track your team's progress
    • View match results and schedules

Tournament Details Shown:

  • Tournament Name: The name of the tournament
  • Status Badge: Shows "Created by you", "Invited", or "Joined"
  • Tournament Code: The 5-character access code (if applicable)
  • Last Updated: When the tournament was last modified
  • Participants: Number of teams/people joined
  • Visibility: Whether it's public or private

What you can do:

  • Open a Tournament: Click "Open" to view and manage a tournament
  • Search Tournaments: Use the search box to filter by name or code
  • Delete a Tournament: Remove tournaments you created (cannot be undone)
  • Toggle Visibility: Hide or show your created tournaments from public

How to use it:

  1. Click the "My Tournaments" button from the home page
  2. View all your tournaments in one list with status indicators
  3. Check the status column to see your role (Created by you, Invited, Joined)
  4. Click "Open" to enter a tournament
  5. Use the search box to find a specific tournament by name or code
💡 Tip: The status indicator quickly shows your role in each tournament—perfect for managing multiple tournaments across different roles!

Find Tournament

Search for and join public tournaments.

What you can do:

  • Search by Name: Find tournaments by their name
  • Search by Code: Find tournaments using their 5-character access code
  • View Public Tournaments: Browse all public tournaments available
  • Join a Tournament: Add yourself as a participant

How to use it:

  1. Click the "Find Tournament" button from the home page
  2. Use the search box to filter tournaments by name or code
  3. Browse the list of public tournaments
  4. Click "Join" to participate in a tournament
  5. To open a tournament by code, enter the 5-character code in the "Enter 5-char code" field and click "Open by code"
💡 Tip: Only public tournaments appear here. Private tournaments can be shared via their access code.

Create Tournament

Create and organize your own pool tournament.

What you can do:

  • Create a New Tournament: Start organizing a tournament
  • Set Tournament Name: Give your tournament a descriptive name
  • Configure Teams: Add teams and players
  • Set Schedule: Configure date, time, and tournament format
  • Generate Draw: Create the playing schedule
  • Manage Results: Record game results and track standings

How to use it:

  1. Click the "Create Tournament" button from the home page
  2. Enter a tournament name
  3. Click "Create" to initialize your tournament
  4. You'll be taken to the tournament management page where you can:
    • Add and invite teams
    • Configure tournament settings
    • Generate the draw/schedule
    • Monitor matches and results
💡 Tip: You'll get a unique 5-character access code for your tournament that you can share with others.

Log out

Sign out of your account.

What you can do:

  • End Your Session: Sign out of your account securely
  • Return to Login: Return to the login/signup page

How to use it:

  1. Click the "Log out" button from the home page
  2. You'll be returned to the login page
  3. You can log back in anytime with your email and password
💡 Tip: Always log out when using a shared or public computer for security.

Getting Started

First Time Users:

  1. Create an Account: Sign up with your email and a secure password
  2. Create a Tournament: Click "Create Tournament" to start organizing
  3. Add Teams: Invite teams to participate
  4. Configure Settings: Set the tournament date, format, and rules
  5. Generate Draw: Create the playing schedule
  6. Manage the Event: Record results and monitor progress

Joining a Tournament:

  1. Ask the tournament organizer for the 5-character tournament code
  2. Click "Find Tournament" on the home page
  3. Enter the code or search by tournament name
  4. Click "Join" to add yourself as a participant
